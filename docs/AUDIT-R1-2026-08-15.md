## 2 · PER SURFACE

### HOME / CHAT

**Broken**
- **The IDEAS drawer is unreachable on phones.** Its only trigger lives in the view bar, which is hidden ≤700px (and the trigger itself hides ≥1100px); the phone tab bar has no IDEAS. The drawer is mounted with no way to open it outside the 701–1099px band (`page.tsx:1580-1587`, `globals.css:7325,1341`).
- Threads sidebar: the `«` collapse button renders below 1100px but its CSS effect only exists ≥1100px — a visible button that does nothing (`ThreadsSidebar.tsx:147`, `globals.css:1138`). Delete timers aren't cleaned on unmount, so a pending delete fires after you leave the view (`ThreadsSidebar.tsx:52-66`).

**Fake / misleading**
- **Fabricated zeros:** if `/api/ideas` fails but the feed succeeds (or vice-versa), the DESK row prints `LIVE 0` / `TRACKED 0` as if measured (`HomeBrief.tsx:241-246,187`).
- The session word has no holiday calendar — it will read MARKET OPEN on Thanksgiving (`HomeBrief.tsx:54-62`).
- WATCHING shows a hardcoded five-symbol list under a personal-sounding label for signed-out users and silently for signed-in users whose watchlist failed to load (`HomeLanding.tsx:38-44,215`).

**Silent failure**
- PULSE and WATCHING have **no loading, empty, error, or stale state**: failures render nothing or leave last-good numbers on screen indefinitely (`HomeBrief.tsx:225-238`, `HomeLanding.tsx:562-574`). A failed threads fetch renders as "no saved threads yet" (`ThreadsSidebar.tsx:83`).

**Integrity labels: none.** Not one home-screen market number carries LIVE/DELAYED labeling; polling cadences (60s/60s/5min) are invisible.

**Duplicated / confusing** — three independent quote pipelines with three hardcoded symbol lists and three byte-identical price formatters on one screen; two sparkline components; two minus glyphs (Unicode vs ASCII) side by side; the DESK row reimplements a parked module with a *different* measure (today's % vs since-called %).

### TERMINAL

**Broken**
- **Movers strip colors are hardcoded**: top-3 always green, bottom-3 always red, regardless of actual sign — on a red day, losers render green (`BookHeatmapModule.tsx:186,193`).
- Options candidates: the ticker button labeled "Load on chart" is wired to an **empty function** (`OptionsWorkspace.tsx:268`).
- The public feed's phone tree initializes desktop-first and swaps after mount — a desktop flash on every phone load (`IdeasFeed.tsx:467-477`).

**Fake / misleading**
- A **hardcoded LIVE chip** in the desk header that stays lit while the StatusBar two rows down says DATA WAITING or DATA STALE (`IntelDashboard.tsx:556`).
- Inspector price block labeled `LIVE · REAL-TIME` over a 30s client poll of a 60s server cache (`:3200`); `LIVE TAPE` badge unconditional (`:750`).
- Mobile TRACKED cards hard-assert `derived:false` for directions that came from extraction (`IdeasFeed.tsx:769`).
- Fallback provider line asserts "Options provider: delayed (Yahoo) · no Greeks" with no data behind it (`OptionsWorkspace.tsx:58`).

**Silent failure** — desk fold-ins (gauge, sectors, catalysts, map) keep stale numbers with no marker when their fetches fail; only the global DATA chip degrades, and only for quotes (`IntelDashboard.tsx:5140,4937,4961`).

**Bare dashes** — a dozen spots render `—` with no distinction between "no data exists," "not fetched," and "provider returned null" (blotter price/delta/spark, option OI/BID/ASK, bull/bear cases, at-the-open). The public feed renders an absent TARGET as *nothing* and an absent ENTRY as `·` in adjacent cells.

**The good news:** the StatusBar (DATA LIVE/STALE/WAITING + latency + ages) and the option ticket (LIVE / DELAYED · YAHOO / as-of ET / "Nothing is estimated") are exactly the label discipline the whole app needs — the R1 pattern already exists in two places.

**Duplicated / confusing** — two full blotters plus a third day-board row set; two detail surfaces; two mobile trees; **seven** sparkline implementations; **four** status vocabularies and **four** direction vocabularies ("BULL" on the desk is "LONG" on the feed); **five** price formatters (`1,234.56` above `$1,234.56`); **seven** date/time formats; the same header labeled DAY BOARD or TRADE BLOTTER for the same rows.

### PIT

**Broken / misleading**
- **No loading state at all**: before `/api/pit` answers (or forever if it fails), the mode screen renders WEEK 1 · ROOKIE, DAILY STREAK 0, and `—` records as facts (`PitSurface.tsx:997,1053,1049`).
- Every round POST sends `bestTrade: 0` — a hardcoded zero written to the server (`:435,479`).
- The result line prints `SPY ±%` — a real ticker symbol naming a simulated series (`:909`).
- The tuning panel unlocks on the *presence* (not validity) of an admin-token key in sessionStorage (`:265-274`).
- DAILY PIT button is pressable-but-inert while attempts are still loading (`:1028`).

**The good news:** simulation labeling is the app's best — persistent banner, `· SIM` painted every frame, SIM chip on every event card.

**Duplicated / confusing** — three canvas renderers with copy-pasted scaling math; currency formatted three ways; the run position written four ways (WEEK 3 · DAY 2 / W3·D2 / week 3 day 2 / 3·2); canvas colors are hardcoded hex, so the PIT ignores the app's themes.

### ADMIN

- A board network failure renders the **empty states** ("nothing on the book yet") beneath a single error line; transcript/tape loader failures are swallowed entirely (`AdminConsole.tsx:175-207`).
- APPROVE ALL / REJECT ALL: per-item failures overwrite each other — a batch with 3 failures shows one message (`:582-597`).
- STALE is a client-side, per-browser judgment (localStorage threshold) — two admins see different flags (`:42,697`).
- REFRESH and RE-ARM are the same PATCH under two labels; demote-to-tape is two writes with no rollback; the app's only native `window.confirm` lives here while two different 6s-undo implementations exist elsewhere (one leaking timers).
- No market numbers render on admin at all (free-text levels only) — nothing to label here.

### LOGIN

- Duplicated private token set — the login page doesn't follow the app's four themes and is the only sentence-case surface (`globals.css:6479`).
- No pending state on submit (button never disables); submit class still named `lp-google` on a magic-link form.

## 3 · API & DATA LAYER

**Raw errors reach callers** — `/api/chat` 500 body literally says "ANTHROPIC_API_KEY is not set. Add it to .env.local and restart the dev server." and pipes raw Anthropic exceptions into the stream (`route.ts:67-72,298-301`); `/api/speak` echoes the ElevenLabs body verbatim while `/api/deepgram-token` handles the identical case correctly; markets/history/quakes/flights/command/inbox/brief/intel all 502 with raw `err.message`.

**Ungated / unlimited** — `/api/intel/settings` GET is world-readable with no gate and no rate limit; `/api/intel/quotes` and `/api/intel/desk` have no rate limit (desk fans out to CNN + Yahoo×11 + Finnhub per uncached miss); the Yahoo options cookie/crumb handshake is publicly triggerable; `/api/threads` GET and thread GET/DELETE have no rate limit.

**Live-but-dead routes** (public HTTP, zero in-app callers — all parked-surface leftovers): `/api/flights`, `/api/quakes`, `/api/command`, `/api/markets`, `/api/markets/history`, `/api/intel` (world RSS), `/api/inbox`, `/api/comms/draft|send`, `/api/day`, `/api/intel/options/chain`.

**A live-feed claim backed by nothing** — the chat prompt injects "Live aircraft (OpenSky)" from a module-global counter that only `/api/flights` populates, and nothing calls `/api/flights` — it is null forever on every fresh instance (`lib/command.ts:154-175`).

**Registry contradicts shipped API** — `PIT_MODES` says `daily: {shipped:false}` while `/api/pit` fully implements it.

**Duplicated pipelines** — two idea stores both rendered on the same screens (`/api/ideas` + `/api/intel/feed`, fetched side-by-side in `IdeasFeed` and `HomeBrief`); two transcript→content pipelines with separate stores, gates, and limits; two "brief" systems that never read each other; **two different Fear & Greed indexes live simultaneously** (CNN equity vs alternative.me crypto); four routes over the same Yahoo chart endpoint with four TTLs; two RSS sets; CRON auth copy-pasted into four files.

**Module-load side effect** — `lib/markets.ts:663` fires `getMarkets()` at import: six external upstreams hit on server boot before any request.

**External-source inventory** (all pre-existing; DATA LAW baseline, none added): Yahoo quotes/bars/screeners/options+crumb, CoinGecko, Coinbase, alternative.me, CNN dataviz (spoofed UA), FairEconomy calendar JSON, FRED (keyed), Finnhub (keyed), USGS, OpenSky (OAuth), YouTube Data v3 + timedtext, Supadata (keyed), 3-feed finance RSS + 6-feed world RSS, Anthropic/Deepgram/ElevenLabs/Gmail/Calendar/Resend. Every anonymous chat turn can fan out to seven of these inside its snapshot timeboxes.

**Stores** — mostly honest on empty (`[]`/`null`/501); `august:intel:fng` has no TTL (never expires); transcripts are namespaced under `ideas:v1` despite being a separate entity; rate limiting fails open (by design, logged) when Upstash is absent.
